# แผนหาลูกค้า 30 วันแรก — One Day Easy

ใช้คู่กับ `founder/customer.json` (กลุ่มลูกค้าและข้อกังวล) และ `founder/pitch.md` (ราคา)
เป้าหมาย: **ลูกค้าจ่ายเงินจริง 20 ร้านใน 30 วัน** (≈ 20–30k บาท) และรู้ว่าช่องทางไหนได้ผลที่สุด

> ราคาในระบบ: เว็บร้าน 990 · เว็บ + โดเมน 1,490 · ดูแลรายปี 990 (ไม่บังคับ) · แก้เกินรอบ 450
> ไม่มีมัดจำ ทำตัวอย่างให้ดูก่อน = จุดขายหลัก ใช้ในทุกข้อความ

## 1. ตัวเลขที่ต้องได้

| ขั้น | ต่อวัน | 30 วัน | อัตราที่สมมติ (ต้องวัดจริง) |
|---|---|---|---|
| ร้านที่ทักไป | 30 | 900 | — |
| ตอบกลับ | 4–5 | 135 | 15% |
| ส่งข้อมูลให้ทำตัวอย่าง | 2 | 54 | 40% ของที่ตอบ |
| จ่ายเงิน | ~0.7 | 20 | 35% ของที่ได้ตัวอย่าง |

ระบบทำตัวอย่างได้วันละ ≥ 5 เว็บ จึงรับได้สบาย · **ตัวชี้วัดที่สำคัญที่สุด: % ที่ได้ตัวอย่างแล้วจ่าย** ถ้าต่ำกว่า 25% แก้ที่หน้าตาเทมเพลตก่อนเพิ่มยอดทัก

## 2. กลุ่มที่เริ่มก่อน (เรียงตามความน่าจะปิดได้)

1. **คาเฟ่เปิดใหม่ < 1 ปี** — อยากดูโปร ยังไม่มีเว็บ จ่ายได้ · หาใน IG/TikTok แฮชแท็ก `#คาเฟ่เปิดใหม่` + ชื่อจังหวัด
2. **ร้านขายดีที่มีลูกค้าประจำ** — อยากให้ค้นเจอใน Google · หาใน Google Maps รีวิว ≥ 100 ที่ยังไม่มีเว็บ
3. **ร้านในย่านท่องเที่ยว** — นักท่องเที่ยวค้นใน Google · เสนอแพ็ก 1,490 พร้อมโดเมน
4. **เต็นท์รถมือสอง** (มีเทมเพลต D1 แล้ว) — ฟอร์มรับซื้อรถส่งเข้า LINE คือจุดขาย
5. **ที่พัก/แคมป์** (เทมเพลต H1 ใหม่) — จองตรงไม่เสียค่าคอมมิชชัน OTA

ข้ามก่อน: ร้านที่ยอดหลักมาจาก Grab/LINE MAN และร้านที่ "ประหยัดทุกบาท" (ปิดยาก)

## 3. ช่องทาง

| ช่องทาง | ทำอะไร | ต่อวัน |
|---|---|---|
| **ทักตรง (หลัก)** | Google Maps → ร้านที่ไม่มีเว็บ → ทัก LINE OA / เพจของร้าน | 20 ร้าน |
| **ทำตัวอย่างก่อนทัก** | เลือกร้านเด่น 3 ร้าน ทำตัวอย่างจากข้อมูลสาธารณะ ส่งลิงก์ไปเลย | 3 ร้าน |
| **คอนเทนต์** | TikTok/Reels "ทำเว็บร้านเสร็จใน 1 วัน" + Facebook กลุ่มเจ้าของร้าน | 1 โพสต์ |
| **บอกต่อ** | ลูกค้าที่จ่ายแล้วแนะนำเพื่อนร้านข้างๆ → ลดค่าดูแลปีแรก 50% | — |

> ทำตัวอย่างก่อนทัก: ใช้เฉพาะชื่อร้าน เมนู ราคา เวลาเปิดที่ร้านเผยแพร่เอง ไม่ใช้รูปของร้านโดยไม่ขออนุญาต (ใช้รูปตัวอย่างจากอัลบัมของเรา) และไม่เปิดเว็บสาธารณะจนกว่าร้านตกลง

## 4. สคริปต์ทักร้าน (คัดลอกใช้ได้)

### 4.1 ทักครั้งแรก — ร้านอาหาร/คาเฟ่
```
สวัสดีค่ะ ร้าน [ชื่อร้าน] 😊
เราทำเว็บไซต์ร้านให้ ลูกค้าค้นชื่อร้านใน Google แล้วเจอเมนู ราคา เวลาเปิด แผนที่ และกดทัก LINE ได้ในหน้าเดียว

ทำตัวอย่างเว็บของร้านให้ดูฟรีก่อน ถูกใจค่อยจ่าย 990 บาท ไม่มีมัดจำ
สนใจให้ทำตัวอย่างไหมคะ แค่ส่งรูปเมนูมาในแชทนี้ได้เลย
```

### 4.2 ส่งพร้อมตัวอย่าง (ทำไว้ก่อน)
```
สวัสดีค่ะ ร้าน [ชื่อร้าน]
เราลองทำตัวอย่างเว็บของร้านจากเมนูที่ร้านลงไว้ ดูได้ที่ลิงก์นี้ค่ะ 👉 [ลิงก์ตัวอย่าง]
ถ้าถูกใจ เปิดใช้จริงได้ทันทีในราคา 990 บาท (ไม่มีมัดจำ แก้ได้อีก 2 รอบ)
ถ้าไม่สนใจ ตอบ "ไม่" ได้เลย เราจะลบตัวอย่างให้ค่ะ
```

### 4.3 เต็นท์รถ
```
สวัสดีครับ เต็นท์ [ชื่อเต็นท์]
เราทำเว็บเต็นท์รถที่ลงรถพร้อมราคาได้ 60 คัน ติดป้าย "ขายแล้ว" เองได้ และมีฟอร์มให้คนส่งรูปรถมาขาย เข้า LINE ร้านทันที
ทำตัวอย่างให้ดูก่อนฟรี ถูกใจค่อยจ่าย สนใจไหมครับ
```

### 4.4 ที่พัก/แคมป์
```
สวัสดีค่ะ [ชื่อที่พัก]
เว็บของที่พักเอง ให้แขกดูห้อง ราคาต่อคืน และทัก LINE จองตรง ไม่เสียค่าคอมมิชชันให้แอปจอง
ทำตัวอย่างให้ดูฟรีก่อน ถูกใจค่อยจ่าย สนใจไหมคะ
```

### 4.5 ตามครั้งที่ 2 (หลัง 3 วัน ไม่ตอบ)
```
ขอส่งตัวอย่างเว็บร้านอื่นที่ทำไว้ให้ดูค่ะ 👉 [ลิงก์ผลงาน]
ถ้าอยากได้แบบนี้ ส่งรูปเมนูมาได้เลย ได้ตัวอย่างภายในวันนี้ค่ะ
```
ไม่ตามเกิน 2 ครั้ง

## 5. ตอบข้อกังวล (จาก customer.json)

| ลูกค้าพูดว่า | ตอบ |

| ไม่มีเวลาเตรียมข้อมูล | ถ่ายรูปเมนูส่งในแชท ระบบอ่านชื่อและราคาให้ คุณแค่ตรวจ |
| ค่ารายปีเป็นภาระ | ไม่บังคับต่อ ปีแรกรวมแล้ว |
| กลัวโอนแล้วเงียบ | ไม่มีมัดจำ เห็นเว็บจริงก่อนจ่าย |
| วันเดียวจริงหรือ คุณภาพดีไหม | ส่งข้อมูลครบเช้า ได้ตัวอย่างภายในวัน · เทมเพลตผ่านการตรวจความอ่านง่ายบนมือถือ |

## 6. คอนเทนต์ 30 โพสต์ (TikTok / Reels / Facebook)

สัปดาห์ 1 — **ทำให้ดู**
1. จับเวลา: จากรูปเมนู → เว็บร้านเสร็จ (ตัดต่อเร็ว)
2. ก่อน/หลัง: เพจที่ต้องเลื่อนหาเมนู vs เว็บหน้าเดียว
3. ลูกค้าค้นชื่อร้านใน Google แล้วเจออะไร
4. 4 ขั้นตอนในแชท LINE
5. ทำไมไม่มีมัดจำ
6. เว็บร้านบนมือถือ: ปุ่มทัก LINE กดได้ทันที
7. รวมเทมเพลต 4 ธุรกิจ

สัปดาห์ 2 — **ข้อกังวล** (ข้อละ 1 โพสต์ ตามตารางข้อ 5) + 1 โพสต์ "แก้เมนูเองได้ พิมพ์ 'แก้เว็บ'"

สัปดาห์ 3 — **ผลงานจริง** (ขออนุญาตร้านก่อน) 1 ร้านต่อโพสต์ + คำพูดเจ้าของร้าน

สัปดาห์ 4 — **ธุรกิจเฉพาะ**: คาเฟ่ ×2 · ร้านอาหาร ×2 · เต็นท์รถ ×2 · ที่พัก ×2 · สรุปเดือน

ทุกโพสต์ปิดด้วย: `ทักไลน์ [@OA] ส่งชื่อร้าน ได้ตัวอย่างฟรีวันนี้`

## 8. ทบทวนทุกสัปดาห์

- อัตราตอบ < 10% → เปลี่ยนประโยคแรก / ช่องทาง
- ได้ตัวอย่างแล้วไม่จ่าย > 70% → ถามเหตุผลทุกร้าน แล้วปรับเทมเพลต/ราคา
- ช่องทางไหนได้ลูกค้าต่อชั่วโมงสูงสุด → ทุ่มเวลาไปช่องทางนั้น

## 9. สิ่งที่ต้องระวัง
