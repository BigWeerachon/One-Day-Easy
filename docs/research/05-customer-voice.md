# เสียงลูกค้า (sales:customer-voice)

> **คำเตือน:** ยังไม่มีลูกค้าจริง ไม่มี CRM ไม่มีบันทึกการคุย ทุกคำพูดด้านล่างคือ **คำพูดจำลอง** จาก `customers-100.json` (สร้างโดย `simulate.mjs`) และ `founder/customer.json` ห้ามนำไปอ้างว่าเป็นคำพูดของร้านจริง
> สกิลนี้ออกแบบให้ใช้คำพูดจริงตามตัวอักษรเท่านั้น ไฟล์นี้จึงเป็นโครงให้แทนด้วยคำพูดจริงหลังสัมภาษณ์ตาม `03-user-research-plan.md`

**แหล่งที่ใช้:** ไฟล์ 2 ไฟล์ข้างต้น · **ไม่ได้ใช้:** บันทึกการคุย (transcripts) อีเมล หรือ CRM เพราะยังไม่มี

## ร่างข้อความแรก (จากเสียงข้างต้น)

**ที่พัก**
```
สวัสดีค่ะ [ชื่อที่พัก] 🏕️
ลองทำหน้าจองห้องของ [ชื่อที่พัก] จากข้อมูลที่ลงไว้ในเพจให้ดูค่ะ 👉 [ลิงก์]
แขกเปิดดูห้อง ราคาต่อคืน แล้วทัก LINE จองตรงได้เลย ไม่ผ่านแอปจอง ไม่เสียค่าคอม
ถ้าถูกใจ เปิดใช้จริง 1,490 บาท (รวมโดเมน) ไม่มีมัดจำค่ะ · ไม่สนใจตอบ "ไม่" ได้เลย จะลบให้ทันที
```

**เต็นท์รถ**
```
สวัสดีครับ เต็นท์ [ชื่อเต็นท์]
ลองทำหน้าร้านของเต็นท์ให้ดูครับ ลงรถพร้อมราคา ติดป้าย "ขายแล้ว" เองได้ 👉 [ลิงก์]
มีฟอร์มให้คนส่งรูปรถมาขาย เข้า LINE เต็นท์ทันที
ถูกใจค่อยจ่าย 1,490 บาท ไม่มีมัดจำครับ
```

## สิ่งที่ยังขาด
- คำพูดจริงจากร้านจริง (ทั้งหมด) → สัมภาษณ์ 15 ร้าน
- ร้านอาหารย่านท่องเที่ยว 10 ร้าน ไม่ได้ตอบเลยในการจำลอง → ไม่มีเสียงของกลุ่มนี้
- งานตามโจทย์ มีตัวอย่าง 1 ราย → ไม่มีข้อมูลพอ
- ถ้าเชื่อมต่อแหล่งบันทึกการคุยหรืออีเมลภายหลัง สกิลนี้จะดึงคำพูดจริงมาแทนได้
