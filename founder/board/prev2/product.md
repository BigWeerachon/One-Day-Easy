# Product lens
Score: 4/10 | Vote: FUND IF

## What is strong
- โฟกัสแคบลงจริง: เหลือร้านอาหารและคาเฟ่ขนาดเล็กที่ยังไม่มีเว็บกลุ่มเดียว ตรงกับหลัก "focus คือการปฏิเสธ"
- เริ่มจากที่ที่ลูกค้าอยู่: ทั้งการสั่ง ตรวจตัวอย่าง และจ่ายเงินอยู่ใน LINE ที่เดียว ไม่ต้องให้เจ้าของร้านเรียนรู้ระบบใหม่ ช่วยลด seam ระหว่างช่องทาง
- มีวินัยด้านคุณภาพในส่วนที่ลูกค้ามองไม่เห็น: QA แก้ได้ 2 รอบ, Dev ตรวจเทคนิค, ส่งต่อคนเมื่อไม่ผ่าน และมี test อัตโนมัติ (unit 66 + e2e 88)

## What would kill it (top 3, most dangerous first)
1. **ผลงานหลักยังเป็น mockup** สิ่งที่ลูกค้าจ่ายเงินซื้อคือหน้าเว็บของร้าน แต่เทมเพลตยังไม่ได้ออกแบบจริง ระบบ agent ที่ดีแค่ไหนก็ส่งของที่ไม่มี taste ได้เร็วเท่านั้น ถ้าตัวอย่างแรกที่ร้านเห็นดูธรรมดา ประสบการณ์จบตั้งแต่ห้านาทีแรก
2. **ทำหลายอย่างเกินไปก่อนพิสูจน์อย่างเดียว** มี 4 แพ็กเกจ + ดูแลรายปี + ค่าแก้เกินรอบ + agent 7 ตัว แต่ยังไม่มีงานจริงสักงาน และไม่เคยจับเวลาว่า "หนึ่งวัน" ทำได้จริงหรือไม่ ทั้งที่ชื่อแบรนด์คือคำสัญญานั้น
3. **รอยต่อที่คนต้องเข้ามา** การตรวจสลิปด้วยมือ งานที่ agent ส่งต่อ และการย้ายจากที่อยู่ฟรีของ Vercel ไปโดเมนลูกค้า เป็นจุดที่ประสบการณ์จะสะดุด ยังไม่รู้ว่าแต่ละจุดใช้เวลารอกี่ชั่วโมง และบนแผนฟรีของ Vercel/Supabase จะรองรับเว็บลูกค้าจริงได้แค่ไหน (คำถามเปิด)

## The questions I would ask the founder
- อธิบายสินค้าในหนึ่งประโยค โดยไม่พูดถึง AI ได้ไหม
- ห้านาทีแรกของเจ้าของคาเฟ่ที่ทัก LINE เป็นอย่างไร เขาเห็นอะไรเป็นอย่างแรก และนานเท่าไรจึงเห็นตัวอย่างเว็บร้านตัวเอง
- ถ้าต้องตัดเหลือแพ็กเกจเดียว จะเหลืออันไหน
- ร้านจะได้อะไรจากเว็บที่ Google Maps, Facebook Page, LINE OA หรือแอปเดลิเวอรีให้ไม่ได้
- ข้อมูลที่ร้านต้องส่ง (รูป เมนู เวลาเปิด) ใช้แรงแค่ไหน และถ้ารูปไม่ดี เว็บจะยังดูดีหรือไม่
- อัตราที่งานถูกส่งต่อคน และเวลารอตรวจสลิปจริงคือเท่าไร (ยังไม่มีข้อมูล)
- ใครเป็นคนออกแบบเทมเพลตจริง และจะเสร็จเมื่อไร

## If FUND IF: the conditions
1. ออกแบบเทมเพลตจริงอย่างน้อย 1 ชุดสำหรับร้านอาหาร/คาเฟ่ ให้ดีพอที่เจ้าของร้านอยากโชว์ ก่อนเพิ่มฟีเจอร์ใดๆ
2. ตัดเหลือแพ็กเกจเดียวสำหรับช่วงทดสอบ
3. deploy ขึ้นระบบจริงและทำงานจริงให้ร้านจริงอย่างน้อย 5 ร้าน จับเวลาตั้งแต่ทักแชทจนเว็บออนไลน์ และบันทึกทุกจุดที่คนต้องเข้ามา
4. เขียนประโยคเดียวที่อธิบายสินค้า แล้วทดสอบกับเจ้าของร้านว่าเข้าใจทันทีหรือไม่
